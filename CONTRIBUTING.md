# Contributing to GDGoC LGU 🚀

First off, thank you for considering contributing to the Google Developer Group on Campus at Lahore Garrison University! We welcome contributions from developers of all skill levels.

Since many of our members are learning Git and GitHub for the first time, here is a step-by-step guide on how to contribute to our repositories.

### Step 1: Find an Issue
Look at the `Issues` tab in the repository. Look for issues labeled `good first issue` or `help wanted`. If you want to work on one, leave a comment saying, "I would like to work on this!" so the core team can assign it to you.

### Step 2: Fork & Clone
1. Click the **Fork** button in the top right corner of the repository to create a copy in your personal GitHub account.
2. Clone your forked repository to your local machine:
   `git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git`

### Step 3: Create a Branch
Always create a new branch for your work. Do not make changes on the `main` branch.
`git checkout -b feature/your-feature-name`

### Step 4: Make Changes & Commit
Make your code changes, save them, and commit them with a clear message.
`git add .`
`git commit -m "Added a new button to the homepage"`

### Step 5: Push & Open a Pull Request (PR)
1. Push your changes to your fork on GitHub:
   `git push origin feature/your-feature-name`
2. Go to the original GDGoC LGU repository and click **Compare & pull request**.
3. Fill out the PR template and submit! A core team member will review your code.

### Need Help?
If you get stuck, don't worry! Ask for help in our `discussions` repository or reach out to a core team member.

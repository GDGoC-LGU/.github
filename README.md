# Hi there! We are GDGoC LGU 👋

Welcome to the official open-source repository for the **Google Developer Group on Campus at Lahore Garrison University**. We are a community-driven group dedicated to helping students build their technical skills and solve real-world problems.

### 🚀 Our Mission
To bridge the gap between theory and practice by providing a platform for students to:
* **Learn** new technologies (Flutter, TensorFlow, Google Cloud, Web).
* **Build** innovative solutions for local community problems.
* **Connect** with industry experts and fellow developers.

### 🛠️ Tech Stack & Topics
* 📱 **Mobile Development:** Android (Kotlin), Flutter
* 🌐 **Web Development:** Angular, React, Firebase
* 🤖 **Machine Learning:** TensorFlow, Keras, Gemini API
* ☁️ **Cloud Computing:** Google Cloud Platform

### 🤝 Contribute
We welcome contributions from all students! Check out our pinned repositories to find "Good First Issues" or join our upcoming hackathons.

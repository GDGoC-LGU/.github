## 🎯 Our Mission

> **We don't just teach tech  we build with it.**

GDGoC LGU is where students go from writing their first `Hello World` to deploying production-grade applications. We're a student-led developer community backed by Google, focused on bridging the gap between **classroom theory** and **real-world engineering**.

Whether you're into mobile apps, cloud infrastructure, AI/ML, or open source  there's a seat at the table for you.

## 🤝 How to Contribute

We're an **open-source-first** community. Every LGU student can contribute  no prior experience needed.

<div align="center">

```mermaid
graph LR
    A[⭐ Star a Repo] --> B[🔍 Find an Issue]
    B --> C[🍴 Fork & Code]
    C --> D[📬 Open a PR]
    D --> E[🎉 Get Merged!]
    style A fill:#4285F4,color:#fff,stroke:none
    style B fill:#EA4335,color:#fff,stroke:none
    style C fill:#FBBC04,color:#000,stroke:none
    style D fill:#34A853,color:#fff,stroke:none
    style E fill:#4285F4,color:#fff,stroke:none
```

</div>

**Quick Start:**

1. **Star** repos you find interesting  it helps us grow
2. Look for issues tagged [`good first issue`](https://github.com/orgs/GDGoC-LGU/issues?q=is%3Aopen+label%3A%22good+first+issue%22)  perfect for newcomers
3. Read the `CONTRIBUTING.md` in any repo before submitting a PR
4. Join **[Community Discussions](https://github.com/orgs/GDGoC-LGU/discussions)** to ask questions, share ideas, or find teammates

## 📅 What We Do

<div align="center">
